# Sevendays Catalog

## Packages

All packages includes **High Resolution** soft copies and a **Laminated Picture** on frame.

- `Pictures` follow a format `quantity size attire` (e.g. 2pcs 2R Toga).
- A `Frame` can sometimes contain a single or multiple pictures.
- `Inch` is used for the unit of measurement except for those sizes using `R`. It has it's own dictionary of sizes.
- `Price` is approximation since the prices vary by branch or location of shoot.
- All packages **Include Usage of**:
  - Toga and Hood
  - Ladies Accessories
  - Executive Attire
  - Barong
  - Filipiniana
