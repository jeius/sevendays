# Landing

The public site: marketing content — packages, services, branches. Customers here are anonymous; all data comes from the API (see its CONTEXT.md for the core vocabulary).

## Language

**Studio Service**:
A standalone studio offering (photo recovery, tarpaulin & bulletin printing, portraits & ID photo, picture framing) showcased on the Services page, with chips for the Branches that offer it. Distinct from an Add-on Service, which attaches to an offering rather than standing alone.
_Avoid_: service (unqualified), other service

**Services page**:
The landing page showcasing Studio Services. Never a list of Add-on Services.
_Avoid_: offerings page

**Conversion hub**:
The Branches page — every primary call-to-action funnels there; each Branch card carries the studio's phone number and a call link.
_Avoid_: contact page

**Deactivated (Service Package)**:
A package that must not appear anywhere on the landing site — not in listings, not reachable by direct URL.
_Avoid_: sold out
